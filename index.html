Shorts Tools

A private, single-operator tool for managing the operator's own YouTube Shorts channels.

Shorts Tools runs only on the operator's own computer. It uses the YouTube Data API and the YouTube Analytics API, with the channel owner's consent, to:

  • upload and schedule videos to the operator's own channels;
  • read the operator's own channel and video analytics (views, watch time, audience retention) to plan future videos.

It is not offered to the public and does not access any other person's account or data.
